# Code of conduct

Vigía is a small project and wants to stay a place where anyone can report a
problem or propose a change without being treated badly for it.

## Expected

- Be respectful, including when you disagree. Criticize code, findings and
  ideas, not people.
- Assume good faith. Many contributors write in a second language: English or
  Spanish are both fine.
- Back technical claims with evidence (a command, a dataset, a paper), the same
  way Vigía's findings do.

## Not accepted

- Harassment, insults, or discriminatory language or imagery of any kind.
- Personal attacks, trolling, or sustained disruption of discussions.
- Publishing someone's private information without their permission.
- Sharing exploit details for an unpatched vulnerability in a public issue
  (use [`SECURITY.md`](SECURITY.md) instead).

## Enforcement

The maintainer may edit or remove comments, issues and pull requests that break
these rules, and may block people who keep doing so. To report a problem
privately, contact the maintainer through their GitHub profile
([@Joshua203-byte](https://github.com/Joshua203-byte)). Reports are kept
confidential.

These rules apply in this repository's issues, pull requests and discussions,
and when representing the project elsewhere.

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
